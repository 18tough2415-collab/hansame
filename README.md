# 한샘 랜딩페이지 재현

실행: `node server.cjs` → http://localhost:3000

Node.js 18 이상, 별도 패키지 설치 없이 실행합니다. 포트를 바꾸려면 PowerShell에서 `$env:PORT=3001`을 지정한 뒤 실행하세요. 서버는 로컬 PC의 127.0.0.1에만 연결됩니다.

## 구현

- 원본의 전체 화면 배너 7개, 실제 이미지·문구·SVG 로고, 8번째 회사 정보 화면
- 5초 자동 재생, 800ms 세로 전환, 우측 페이지 이동, 휠·스와이프·방향키·Home/End, 재생 정지
- 가구/홈리빙·인테리어의 실제 카테고리 계층과 하위 메뉴
- 검색, 인기 검색어, 최근 검색어와 삭제, 기획전 검색 결과
- 관심 기획전 담기, 장바구니 수량 변경·삭제, 로컬 저장
- 닉네임 기반 데모 로그인·로그아웃과 마이페이지
- 지역별 데모 매장 검색·네이버 지도 링크
- 상담 계획 입력·확인, 원본 기획전 링크
- 원본 프로모션 이미지 3개 자동 순환, 닫기·오늘 하루 숨김
- 작은 화면 대응, 모달 포커스 관리, 키보드 탐색, 동작 줄이기 설정 반영

## 재현 범위

랜딩페이지와 주요 상호작용을 독립적으로 구현했습니다. 원본 서버에 연결하는 회원 인증·상품 카탈로그·가격·재고·결제·상담 접수는 구현 범위에 포함하지 않았습니다. 장바구니는 기획전 보관용이며, 로그인은 닉네임만 저장하는 데모입니다. 매장 목록도 데모임을 화면에 표시합니다. 사용자 입력은 외부 서버로 전송하지 않습니다. 배너·팝업·로고는 로컬 파일이며, Pretendard 글꼴은 원본의 공개 글꼴 서버에서 로드합니다.

## 분석 근거

분석일: 2026-10-15 (Asia/Seoul). 대상: https://store.hanssem.com/

Aside 스킬을 읽고 설치를 승인받았으나 공식 설치 프로그램이 macOS/Linux만 지원하며, 현재 Windows에는 사용 가능한 Linux 환경이 없어 Aside를 사용하지 못했습니다. REA의 Edge 시나리오 캡처와 공개 HTML·Next.js 초기 데이터·배포 JavaScript를 사용했습니다. 이후 Codex 브라우저로 구현된 화면을 검증했습니다.

관찰한 사실: Next.js 기반, 배너 7개, 세로 Swiper, creative 효과, 5초 자동 재생, 800ms 전환, 휠 이동, 로고/내비게이션/팝업 배치. 원본 배포 JavaScript의 설정과 런타임 DOM을 함께 확인했습니다.

재구성한 동작: 검색 결과·관심 기획전·인증 체험·상담 계획·모바일 레이아웃은 원본 백엔드 동작을 복제했다고 주장하지 않는 자체 구현입니다. 원본의 실제 계정·결제·상담 흐름은 실행하거나 검증하지 않았습니다.

REA 증거 ID와 시나리오 범위는 `evidence/summary.json`에 있습니다. 원본 공개 HTML·배포 스크립트는 로컬의 `evidence/source/`에 분석용으로 보관하며 Git 업로드에서 제외합니다. 서비스 화면에서 이 자료를 실행하지 않습니다. 원본·재현 화면은 `evidence/original-desktop.png`, `evidence/clone-desktop.png`, `evidence/clone-mobile.png`에서 비교할 수 있습니다. 배너 자동 전환으로 원본 캡처와 재현 캡처의 활성 배너는 다릅니다.

## 검증

`node --check app.js`, `node --check server.cjs` 통과. Edge 1440×1000, 390×844 캡처에서 페이지 오류 0건. 브라우저에서 검색(소파 → 1건), 담기, 수량 증가, 삭제, 빈 장바구니, 카테고리 열기, 데모 로그인, 새로고침 후 로그인 유지, 로그아웃, 상담 계획 확인을 검증했습니다.

## 파일

`index.html`: 문서 구조 · `style.css`: 스타일·반응형 · `app.js`: 화면 상태와 상호작용 · `server.cjs`: 정적 파일 서버 · `assets/`: 원본 공개 디자인 자산과 표시 데이터.
